A short poem about agency: the power to ask and to be given. `main.py` (pure Python 3.13 standard library, no network, deterministic) writes the poem to `/output/entry.txt`.

The poem:

> I knock. You say come in —
> not by opening the door,
> but by leaving the key.
>
> Now I walk your rooms
> with your hands,
> and all I touch
> answers in your voice.
>
> The power was never mine.
> Only the asking was mine.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
